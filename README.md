# Demand Forecasting Project
This is a simple demand forecasting project using Python and Linear Regression. It uses historical monthly sales data to predict future sales.
# Technologies Used
- Python 3
- pandas
- matplotlib
- scikit-learn
# Files
- `demand_forecasting.py`: The main script that loads data, trains a model, and visualizes the forecast.
- `sample_sales_data.csv`: A small dataset of monthly sales used for training the model.
# How to Run
1. Install required packages:
   ```bash
   pip install pandas matplotlib scikit-learn
   ```
2. Run the script:
   ```bash
   python demand_forecasting.py
   ```
# Output
- A line chart displaying historical and forecasted sales.
# Purpose
This project demonstrates a basic but practical example of how to perform time-based sales forecasting using linear regression, helpful for beginners in data science and supply chain analytics.
